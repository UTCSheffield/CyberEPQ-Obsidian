# Essay writing Activity 1

Write a 300 word introduction, explaining the meaning of the project title and the key terms in it. This must contain at least two in-text citations. You should use the Harvard Referencing style to reference the sources and evidence used.

 Either proper references at the end or the lines from you Evaluation Table of Resources so I can check the citations are correctly formatted.
